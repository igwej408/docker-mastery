# Docker Mastery

A 30-day, 30-minutes-a-day journey from Docker basics to a production-style, CI-built, containerized service. Every day produces a note; every week produces something shippable.

## Portfolio projects
| # | Project | What it shows |
|---|---|---|
| 1 | [Containerized Java CLI](projects/01-java-cli-container) | Dockerfiles, multi-stage builds, image size optimization |
| 2 | [Compose stack](projects/02-compose-stack) | Multi-container apps, networking, volumes, healthchecks |
| 3 | [CI pipeline](projects/03-ci-pipeline) | GitHub Actions, registry push, image scanning |
| 4 | [Capstone service](projects/04-capstone) | Everything combined, documented end to end |

## How this repo works
- [ROADMAP.md](ROADMAP.md): the full 30-day plan
- `notes/`: one note per day (fill in as you go)
- `docs/cheatsheet.md`: commands and concepts, growing daily
- `projects/`: the portfolio projects
